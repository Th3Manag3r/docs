# 2.10: Conditional branching: `if`, `?`

## The `if` statement
- evaluates the condition expression and converts it to boolean
    - `falsy` value: a value that returns `false` when converted to boolean
    - `truthy` value: a value that returns `true` when converted to boolean
- curly braces are not required for a single-line body

```js
if (condition) {
    // code
} else if (condition) {
    // code
} else {
    // code
};

if (condition)
    // single line code
else if (condition)
    // single line code
else
    // single line code
```

## the conditional operator `?`
- also called the `question mark` operator.
- only expressions can be used with the ternary operator.
```js
condition ? value1 : value2;

condition1 ? value1 :
    condition2 ? value2 : value3;
```



# 2.11: Logical operators
- there are 4 logical operators in JS: `&&`, `||`, `!`, `??`.
- non boolean operands get converted to boolean.

## OR `||`
- returns the first truthy value or the last one if no truthy value is found.
- `short-circuit` evaluation: `||` processes its argument until the first truthy value is reached.

## AND `&&`
- returns the first falsy value or the last one if no falsy value is found.

## NOT `!`
- converts the operand to boolean and returns the inverse.
- a double NOT `!!` is used to convert a value to boolean.



# 2.12: Nullish coalescing operator `??`
- it treats `null` and `undefined` similarly.
- returns the first operand that is not `null` or `undefined`.

## using `??` with `&&` or `||`
- for safety reasons JS forbids using `??` with `&&` and `||` unless the precedence is explicitly specified with parentheses.
```js
const x = value1 && value2 ?? value33;    // syntax error
const x = (value1 && value2) ?? value33;    // syntax error
```



# 2.13: Loops: while and for
- a single execution ofthe loop body is called `iteration`
- curly braces are not required for a single-line body

## The `while` loop
```js
while (condition) {
    // code
};

while (condition)
    // single line code
```

## The `do...while` loop
- used when the body of the loop should execute at least once regardless of the condition being truthy.
```js
do {
    // code
} while (condition);

do 
    // single line code 
while (condition);
```

## The `for` loop
- `begin`: executes once upon entering the loop.
- `condition`: checked before every loop iteration. if `false` the loop stops.
- `step`: executes after the body on each iteration.

- any part of `for` can be skipped.
```js
for (begin; condition; step) {
    // code
};

for (begin; condition; step)
    // single line code

for (;;) {
    // infinite loop
}
```

## breaking and continuing the loop
- the `break` directive is used to exit the loop at any time.
- the `continue` directive is used to stop the current iteration and go to the next one.
- `break` and `continue` are not `expressions` they are `directives`.
- they are not allowd in the right side of the ternary operator `?`.

## labels for `break`/`continue`
- a `label` is an identifier with a colon before a loop.
- without `label` the `break`/`continue` would only affect the nearest/inner loop.
```js
label: for (begin; condition; step) {
    for (begin; condition; step) {
        break label;
    }
}

label:
for (begin; condition; step) {
    for (begin; condition; step) {
        break label;
    }
}
```

- a `continue` is only possible from inside a loop.
- a `break` directive must be inside a code block.
- any "labelled" code block will do.
```js
// this works
label: {
    // code 
    break label;
    // code
}

// syntax error
{
    // code 
    break;
    // code
}
```



# 2.14: the `switch` statement
- can replace multiple `if` checks
- has one or more `case` blocks and an optional default.
- the `default` case does not have to be at the end.
- `x` is checked for a strict equality to the `value` from the first case then to the second and so on.
- if the equality is found the code in a case is executed until the nearest `break` or until the end of the `switch`.
- if no case is matched then the `default` code is executed if its exist.
- any expression can be a case argument.
- several cases can share the same code (can be grouped).
- the grouping is a side effect of how `switch` works without `break`.
```js
switch(x) {
    case value1:
        // code
        break; // optional
    case value2:
    case value3:
        // code
        break; // optional
    default:
        // code
        break; // optional
}
```
