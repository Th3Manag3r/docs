# functions

- variables declared inside a function is only visible inside the function.
- a function can access an outer variable.
- if a same-named variable is declared inside the function it shadows the outer one.

- `global variables`: variables declared outside of any function.
- it is a good practice to minimize the use of `global variables`.

## parameters
- a `parameter` is the value listed inside the parentheses in the function delaration. 
- an `argument` is the value that is passed to the function when it is called (it is a call-time term).

## default values
- old versions of JS didn't support default values
- the default value for an argument if not provided is `undefined`.
- a default value can be specified explicitly.
- if we pass `undefined` as an argument the default value is jumps in.
- a default value is evaluated every time the function is called without the respective parameter.

## returning a value
- the `return` directive can be used to return a value from a function.
- a function with an empty `return` or without it returns `undefined`. 
- never add a newline between `return` and teh value. because JS assumes a semicolon after `return`. it becomes an empty return.

```js
// function declaration
function functionName(parameter1, param2 = "defaultVal", param3 = notEvaluatedNow() ) {
    // code
}
```



# 2.16: function expressions
- in JS a function is a special kind of value.

```js
// function expression
const functionName = function(param1, param2 = "default", param3 = notEvaluatedNot()) {
    // code
}
```

## function declaration vs function expression
- a function expression is created when the execution reaches it and is usable only from that moment.
- A function declaration can be called earlier than it is defined.
    - when JS prepares to run the script it first looks for global function declarations in it and creates the functions.
    - after all function declarations are processed teh code is executed. so it has access to these functions.
- in `strict mode` when a function declaration is within a code block, it is visible everywhere inside the block but not outside of it.



# 2.17: arrow functions, the basics
- if we have only one argument, parentheses around it can be ommited.
- If there are no arguments, parentheses are empty, but they must be present.
```js
// arrow function
const functionName = (arg1, arg2 = "default", param3 = notEvaluatedNot()) => {
    // code
}
```
