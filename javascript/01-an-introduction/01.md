# 1.1 An Introduction to JavaScript

## what is JavaScript
- `ECMA-262` is the technical specification document/standard.
- `ECMAScript` is the programming language specification.
- `JavaScript` is a programming language based on ECMAScript, with additional environment-specific APIs/features.
- `ECMAScript` languages do not include APIs like the DOM, these are environment-specific features.
- for example DOM APIs and some other browser specific methods are part of the WHATWG standards.
- `JavaScript` can execute on the browse, the server or any device that has a `JavaScript Engine`.
- `JavaScript` can also create mobile apps.
- the browser has an embedded engine sometimes called a `Javascript Virtual Machine` 
    - `V8` in chrome, opera and edge.
    - `SpiderMonkey` in firefox.
    - `Chakra` in IE.
    - `JavaScriptCore`, `Nitro` and `SquirrelFish` for safari.
